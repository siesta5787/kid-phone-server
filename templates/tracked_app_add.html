Either watch a GitHub repo's Releases for a new APK and push it to devices automatically, or upload APKs yourself whenever a new version is ready. Both work the same way once set up - devices get updates either way, silently.

Only needed if a release has more than one APK (e.g. per architecture) - the first asset whose filename contains this text is used.

Needed for a repo that only ever publishes to a rolling/pre-release tag (like this project's own launcher) - otherwise a repo with no full releases will never be found.
