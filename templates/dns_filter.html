Connect your kid's device

  1. In the Tailscale admin console, find this Pi, open its route settings, and turn on "Use as exit node".
  2. {% if let Some(ip) = tailscale_ip %} On the kid's device, set this Pi as its exit node - this Pi's tailnet IP is {{ ip }}. {% else %} On the kid's device, set this Pi as its exit node (its tailnet IP will show here once Tailscale is running on the Pi). {% endif %}
  3. Turn on "Require Tailscale to stay connected" on that device's page, with this as its exit node, so it can't be bypassed.

Other devices on your tailnet are unaffected unless they also choose this Pi as their exit node.
