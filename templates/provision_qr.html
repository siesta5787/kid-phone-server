Provision {{ device.name }}

This QR code carries a fresh one-shot enrollment code for this device, plus your server URL and Tailscale key from Provisioning settings - scanning it does setup and enrollment in one step. It goes stale the moment you leave this page or generate another one, same as a plain enrollment code.

Two ways to scan it

  1. Stock Android / most custom ROMs (not GrapheneOS): factory reset (or use a device fresh out of the box), tap the same spot on the Welcome screen 6 times, then scan. Setup downloads and installs the launcher, sets it as device owner, and applies the server URL/Tailscale key/enrollment code automatically - no other steps.
  2. GrapheneOS, or anywhere the flow above isn't available: set up the device and grant Device Owner via adb shell dpm set-device-owner as usual, then open the launcher's Settings and use "Scan setup QR" - same code, same result, just triggered from inside the app instead of Android's own setup wizard.

WiFi (optional, native flow only)

Only used by the stock-Android zero-touch flow, to join a network before the launcher downloads. Ignored by the in-app scanner, since the device is already online by that point.
